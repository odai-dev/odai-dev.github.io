# Personal Developer Portfolio Website (v1)

The source code for Odai's personal developer portfolio website hosted on GitHub Pages, featuring project highlights, technical skillsets, and professional contact links.

---

## 🌟 Sections
- **Hero & Identity**: Overview of engineering background and core competencies.
- **Selected Projects**: Cards highlighting top web applications, browser extensions, and systems projects.
- **Skills Matrix**: Breakdown across languages (Rust, C++, Python, TypeScript), frameworks, and tooling.
- **Contact & Socials**: Direct links to GitHub, LinkedIn, and email.
